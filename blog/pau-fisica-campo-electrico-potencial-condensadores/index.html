Campo eléctrico en PAU: cómo dominar potencial, trabajo y condensadores sin perder los signos

El campo eléctrico se complica cuando se mezclan magnitudes vectoriales y escalares. La fuerza y el campo necesitan dirección; el potencial y la energía se suman con signo. Separar esas dos capas evita casi todos los errores de PAU.

Respuesta directa. Calcula el campo como suma vectorial y el potencial como suma algebraica. Después usa F⃗=qE⃗\vec F=q\vec EF=qE, U=qVU=qVU=qV y Wcampo=−ΔUW_{campo}=-\Delta UWcampo​=−ΔU. Antes de operar, fija el signo de cada carga y el sentido del desplazamiento.

Campo de una carga puntual

Una carga QQQ crea a distancia rrr:

E⃗=kQr2r^.\vec E=\frac{kQ}{r^2}\hat r.E=r2kQ​r^.

Si Q>0Q>0Q>0, apunta hacia fuera; si Q<0Q<0Q<0, hacia la carga. El módulo es siempre positivo, pero el vector incorpora dirección y sentido. Para varias cargas:

E⃗total=∑iE⃗i.\vec E_{total}=\sum_i\vec E_i.Etotal​=i∑​Ei​.

Conviene dibujar cada contribución antes de descomponer en ejes.

Potencial y superposición

El potencial de una carga puntual, tomando cero en el infinito, es:

V=kQr.V=\frac{kQ}{r}.V=rkQ​.

Es escalar:

Vtotal=k∑iQiri.V_{total}=k\sum_i\frac{Q_i}{r_i}.Vtotal​=ki∑​ri​Qi​​.

Dos campos pueden cancelarse en un punto mientras el potencial no es cero, o al revés. No existe contradicción: E⃗\vec EE mide variación espacial de VVV y cumple E⃗=−∇V\vec E=-\nabla VE=−∇V.

Energía y trabajo

Para una carga de prueba qqq:

U=qV,ΔU=q(VB−VA).U=qV, \qquad \Delta U=q(V_B-V_A).U=qV,ΔU=q(VB​−VA​).

El trabajo realizado por el campo es:

Wcampo=−ΔU=q(VA−VB).W_{campo}=-\Delta U=q(V_A-V_B).Wcampo​=−ΔU=q(VA​−VB​).

Si sólo actúa la fuerza eléctrica, la disminución de energía potencial se transforma en energía cinética. Una carga positiva tiende espontáneamente hacia menor potencial; una negativa, hacia mayor potencial.

Ejemplo de movimiento

Un electrón parte del reposo y atraviesa una diferencia de potencial de módulo 250 V250\ \mathrm V250 V. La ganancia de energía cinética es:

ΔK=e∣ΔV∣=(1.60×10−19)(250)=4.0×10−17 J.\Delta K=e|\Delta V| =(1.60\times10^{-19})(250) =4.0\times10^{-17}\ \mathrm J.ΔK=e∣ΔV∣=(1.60×10−19)(250)=4.0×10−17 J.

En electronvoltios son 250 eV250\ \mathrm{eV}250 eV. Para hallar la velocidad no relativista:

12mev2=ΔK.\frac12m_ev^2=\Delta K.21​me​v2=ΔK.

Superficies equipotenciales

Mover una carga sobre una superficie equipotencial no cambia UUU, por lo que el campo no realiza trabajo. Las líneas de campo cortan esas superficies perpendicularmente y apuntan hacia potencial decreciente.

En un campo uniforme entre placas:

E=∣ΔV∣d.E=\frac{|\Delta V|}{d}.E=d∣ΔV∣​.

Esta relación no debe aplicarse automáticamente al campo radial de una carga puntual.

Condensadores

La capacidad se define como:

C=QV.C=\frac{Q}{V}.C=VQ​.

Para placas paralelas ideales:

C=εAd.C=\frac{\varepsilon A}{d}.C=dεA​.

La energía almacenada puede escribirse de tres formas equivalentes:

UC=12CV2=Q22C=12QV.U_C=\frac12CV^2=\frac{Q^2}{2C}=\frac12QV.UC​=21​CV2=2CQ2​=21​QV.

Elegir la forma adecuada depende de qué magnitud permanece constante al cambiar geometría o dieléctrico.

Errores que restan puntos

  • Sumar módulos de campo sin respetar direcciones.
  • Usar rrr en lugar de r2r^2r2 para EEE.
  • Confundir trabajo del campo con trabajo externo.
  • Omitir el signo de la carga al calcular energía.
  • Aplicar E=ΔV/dE=\Delta V/dE=ΔV/d fuera de un campo uniforme.
  • Confundir carga de una placa con carga neta del condensador.
