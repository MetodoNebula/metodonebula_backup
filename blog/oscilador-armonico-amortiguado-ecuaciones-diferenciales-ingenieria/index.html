El oscilador masa–muelle amortiguado conecta Ecuaciones Diferenciales, Física y Vibraciones. El enunciado puede hablar de una suspensión, un sensor o una máquina, pero el modelo básico es el mismo: inercia, fuerza recuperadora y rozamiento proporcional a la velocidad.

Respuesta directa. El modelo libre amortiguado es mx′′+cx′+kx=0m x''+c x'+kx=0mx′′+cx′+kx=0. La relación entre c2c^2c2 y 4mk4mk4mk decide si el movimiento oscila, vuelve al equilibrio lo más rápido posible o vuelve sin oscilar.

Construir el modelo físico

Para un desplazamiento x(t)x(t)x(t) respecto al equilibrio:

  • La fuerza elástica es −kx-kx−kx.
  • La fuerza de amortiguamiento viscoso es −cx′-cx'−cx′.
  • La segunda ley de Newton da:
mx′′=−cx′−kx.m x''=-cx'-kx.mx′′=−cx′−kx.

Reordenando:

mx′′+cx′+kx=0.m x''+cx'+kx=0.mx′′+cx′+kx=0.

Las unidades ayudan a detectar errores: mx′′m x''mx′′, cx′cx'cx′ y kxkxkx deben tener unidades de fuerza.

Ecuación característica

Buscamos soluciones de la forma x(t)=ertx(t)=e^{rt}x(t)=ert. La ecuación característica es:

mr2+cr+k=0.mr^2+cr+k=0.mr2+cr+k=0.

Su discriminante es:

Δ=c2−4mk.\Delta=c^2-4mk.Δ=c2−4mk.

No clasifiques el movimiento mirando solo si ccc es “grande”. Debes compararlo con 2mk2\sqrt{mk}2mk​.

Subamortiguado: todavía hay oscilación

Si c2<4mkc^2<4mkc2<4mk, las raíces son complejas:

r=−c2m±iωd,r=-\frac{c}{2m}\pm i\omega_d,r=−2mc​±iωd​,

donde:

ωd=km−(c2m)2.\omega_d=\sqrt{\frac{k}{m}-\left(\frac{c}{2m}\right)^2}.ωd​=mk​−(2mc​)2​.

La solución tiene la forma:

x(t)=e−ct/(2m)[Acos⁡(ωdt)+Bsin⁡(ωdt)].x(t)=e^{-ct/(2m)} \left[A\cos(\omega_dt)+B\sin(\omega_dt)\right].x(t)=e−ct/(2m)[Acos(ωd​t)+Bsin(ωd​t)].

La envolvente exponencial disminuye con el tiempo, mientras seno y coseno describen las oscilaciones. Es el caso típico de una vibración que se va apagando.

Amortiguamiento crítico y sobreamortiguado

Si c2=4mkc^2=4mkc2=4mk, hay una raíz doble. La solución es:

x(t)=(A+Bt)e−ct/(2m).x(t)=(A+Bt)e^{-ct/(2m)}.x(t)=(A+Bt)e−ct/(2m).

El sistema regresa al equilibrio sin oscilar y, dentro de este modelo, tan rápido como es posible sin sobrepasarlo.

Si c2>4mkc^2>4mkc2>4mk, aparecen dos raíces reales negativas distintas. El retorno también es sin oscilación, pero suele ser más lento. Más amortiguamiento no implica siempre una vuelta más rápida.

Ejemplo de clasificación

Para m=1m=1m=1 kg, k=25k=25k=25 N/m y c=6c=6c=6 N·s/m:

c2−4mk=36−100=−64.c^2-4mk=36-100=-64.c2−4mk=36−100=−64.

Como es negativo, el sistema es subamortiguado. Su frecuencia amortiguada es:

ωd=25−9=4 rad/s.\omega_d=\sqrt{25-9}=4\text{ rad/s}.ωd​=25−9​=4 rad/s.

Después se usan las condiciones iniciales x(0)x(0)x(0) y x′(0)x'(0)x′(0) para calcular AAA y BBB.

Errores frecuentes

  • Usar kxkxkx como fuerza positiva sin fijar un eje y signos coherentes.
  • Confundir frecuencia natural k/m\sqrt{k/m}k/m​ con frecuencia amortiguada.
  • Decir que el amortiguamiento crítico oscila una vez.
  • Olvidar que las constantes se determinan con posición y velocidad inicial.
  • Aplicar este modelo a un sistema con fuerza externa sin añadir el término de forzamiento.
