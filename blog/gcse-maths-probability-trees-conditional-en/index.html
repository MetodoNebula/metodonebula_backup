Master GCSE probability trees: dependent events, sampling without replacement, conditional probability, branch products and checks.

A probability tree is more than a diagram carrying fractions. Each route represents an intersection of events and each split must contain probabilities conditional on what has already happened.

Direct answer. Multiply probabilities along one route because all its events must occur. Add complete routes when any of them gives the required result. Without replacement, update both numerator and denominator after the first selection.

Rules that build the tree

At every split, branch probabilities add to 1:

P(A)+P(Ac)=1.P(A)+P(A^c)=1.P(A)+P(Ac)=1.

For a two-stage route:

P(A∩B)=P(A)P(B∣A).P(A\cap B)=P(A)P(B\mid A).P(A∩B)=P(A)P(B∣A).

P(B∣A)P(B\mid A)P(B∣A) means the probability of B given that A has occurred. It need not equal P(B)P(B)P(B).

Replacement and independence

A bag contains 3 red balls and 2 blue balls. One ball is taken, replaced and a second is taken. The probability of two reds is:

P(RR)=35⋅35=925.P(RR)=\frac35\cdot\frac35=\frac9{25}.P(RR)=53​⋅53​=259​.

The bag returns to its original composition, so the selections are independent in this model.

Getting one of each colour has two routes:

P(RB or BR)=3525+2535=1225.P(RB\text{ or }BR)=\frac35\frac25+\frac25\frac35=\frac{12}{25}.P(RB or BR)=53​52​+52​53​=2512​.

Multiplying only one route would omit a possible order.

Without replacement

Using the same bag without returning the first ball:

P(RR)=35⋅24=310.P(RR)=\frac35\cdot\frac24=\frac3{10}.P(RR)=53​⋅42​=103​.

After one red has been removed, 2 reds remain among 4 balls. If the first ball were blue, the second red probability would be 3/43/43/4. Each second branch depends on the first outcome.

Conditional probability from data

The definition is:

P(A∣B)=P(A∩B)P(B),P(A\mid B)=\frac{P(A\cap B)}{P(B)},P(A∣B)=P(B)P(A∩B)​,

provided P(B)>0P(B)>0P(B)>0. The denominator restricts the sample space to cases where B occurred.

If 40 students play sport, 18 of those also play an instrument, and there are 100 students in total:

P(I∣S)=18/10040/100=1840=0.45.P(I\mid S)=\frac{18/100}{40/100}=\frac{18}{40}=0.45.P(I∣S)=40/10018/100​=4018​=0.45.

Dividing by 100 would answer P(I∩S)P(I\cap S)P(I∩S) instead of the conditional question.

Reversing a tree and Bayes' rule

A tree may give P(A)P(A)P(A), P(B∣A)P(B\mid A)P(B∣A) and P(B∣Ac)P(B\mid A^c)P(B∣Ac) but ask for P(A∣B)P(A\mid B)P(A∣B). First calculate:

P(B)=P(A)P(B∣A)+P(Ac)P(B∣Ac),P(B)=P(A)P(B\mid A)+P(A^c)P(B\mid A^c),P(B)=P(A)P(B∣A)+P(Ac)P(B∣Ac),

then:

P(A∣B)=P(A)P(B∣A)P(B).P(A\mid B)=\frac{P(A)P(B\mid A)}{P(B)}.P(A∣B)=P(B)P(A)P(B∣A)​.

A condition cannot be reversed by swapping letters. P(A∣B)P(A\mid B)P(A∣B) and P(B∣A)P(B\mid A)P(B∣A) use different restricted sample spaces.

Quick checks

  • Each pair of branches from one node adds to 1.
  • Every probability lies between 0 and 1.
  • All complete end routes add to 1.
  • Without replacement, the total number of objects falls.
  • “At least one” may be easier as 1−P(none)1-P(\text{none})1−P(none).

Common mistakes

  • Adding probabilities along one route.
  • Multiplying alternative routes.
  • Keeping the same denominator without replacement.
  • Confusing mutually exclusive and independent events.
  • Rounding each branch before the final result.
