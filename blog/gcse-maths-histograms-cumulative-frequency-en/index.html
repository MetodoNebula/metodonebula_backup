GCSE Maths: histograms and cumulative frequency without confusing height and area

Learn histograms, frequency density and cumulative frequency in GCSE Maths through calculation, interpretation and error checks.

In a bar chart, height may represent frequency. In a histogram with unequal class widths, that rule fails: the area of each bar represents frequency. Its height is frequency density.

The essential formula

frequency density=frequencyclass width.\text{frequency density}=\frac{\text{frequency}}{\text{class width}}.frequency density=class widthfrequency​.

Equivalently, frequency=density×class width\text{frequency}=\text{density}\times\text{class width}frequency=density×class width. This is base times height: the bar's area.

The third class has a greater frequency than the second but a lower bar because it is twice as wide. Area, not height alone, preserves the 24 observations.

Recovering a frequency from the graph

If a bar runs from 30 to 50 with density 1.6:

f=(50−30)⋅1.6=32.f=(50-30)\cdot1.6=32.f=(50−30)⋅1.6=32.

There are 32 observations in that interval. Write the width explicitly so that 50 is not mistaken for the base.

Cumulative frequency

Cumulative frequency adds every observation up to each upper class boundary. Frequencies 8,18,24,58,18,24,58,18,24,5 give cumulative totals 8,26,50,558,26,50,558,26,50,55.

Plot the upper boundaries against these totals and join them with an increasing curve. It must never fall: adding another class cannot reduce the running total.

Median and quartiles from the curve

For NNN values, locate:

Q1:N4,median:N2,Q3:3N4.Q_1:\frac N4,\qquad \text{median}:\frac N2,\qquad Q_3:\frac{3N}{4}.Q1​:4N​,median:2N​,Q3​:43N​.

Move horizontally to the curve and then down to the value axis. Grouped data give estimates. The interquartile range IQR=Q3−Q1IQR=Q_3-Q_1IQR=Q3​−Q1​ measures the central spread and is less sensitive to extremes than the full range.

Estimating inside a class

A cumulative curve can estimate how many values lie below a point inside a class. A table calculation usually assumes a uniform distribution within the interval. State that assumption: the original individual values are unavailable.

Common mistakes

  • Setting height equal to frequency for unequal classes.
  • Using the upper boundary instead of the difference as class width.
  • Leaving gaps between continuous intervals.
  • Plotting class midpoints on a cumulative frequency graph.
  • Reading quartiles at N/3N/3N/3 and 2N/32N/32N/3.
  • Reporting an estimate as exact.

Quick checks

The total bar area must represent the total frequency. The final cumulative value must equal NNN, and Q1<median<Q3Q_1<\text{median}<Q_3Q1​<median<Q3​ with a positive IQR.
