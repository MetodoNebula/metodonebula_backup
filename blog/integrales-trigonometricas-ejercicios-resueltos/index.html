Integrales trigonométricas: ejercicios universitarios resueltos

Las integrales trigonométricas no se resuelven memorizando una lista extensa: primero identifica si una derivada interior está presente, si conviene usar una identidad o si una potencia impar permite separar un factor.

Respuesta directa. Si aparece una función con su derivada, usa sustitución. Para potencias de seno y coseno, separa un factor cuando una potencia es impar; si ambas son pares, usa identidades de ángulo doble.

Sustitución directa

∫sin⁡xcos⁡x dx.\int\sin x\cos x\,dx.∫sinxcosxdx.

Tomamos u=sin⁡xu=\sin xu=sinx, du=cos⁡x dxdu=\cos x\,dxdu=cosxdx. Entonces:

∫u du=u22+C=sin⁡2x2+C.\int u\,du=\frac{u^2}{2}+C=\frac{\sin^2x}{2}+C.∫udu=2u2​+C=2sin2x​+C.

Potencias con exponente impar

Para:

∫sin⁡3xcos⁡x dx,\int\sin^3x\cos x\,dx,∫sin3xcosxdx,

separa sin⁡3x=sin⁡x(1−cos⁡2x)\sin^3x=\sin x(1-\cos^2x)sin3x=sinx(1−cos2x) si eliges u=cos⁡xu=\cos xu=cosx, o usa u=sin⁡xu=\sin xu=sinx dejando sin⁡2x=1−cos⁡2x\sin^2x=1-\cos^2xsin2x=1−cos2x según el factor disponible. La elección debe hacer aparecer dududu.

Potencias pares

En:

∫sin⁡2x dx,\int\sin^2x\,dx,∫sin2xdx,

usamos sin⁡2x=(1−cos⁡2x)/2\sin^2x=(1-\cos2x)/2sin2x=(1−cos2x)/2:

∫sin⁡2x dx=x2−sin⁡2x4+C.\int\sin^2x\,dx=\frac{x}{2}-\frac{\sin2x}{4}+C.∫sin2xdx=2x​−4sin2x​+C.

Errores frecuentes

  • Cambiar variable sin transformar toda la integral.
  • Usar una identidad que complica la expresión.
  • Olvidar la constante CCC.
  • No derivar el resultado para comprobarlo.
